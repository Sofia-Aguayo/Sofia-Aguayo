## Projects

### Nanosatellite Star Tracker — Lost-In-Space Identification

Machine learning system developed as part of my Engineering Physics thesis to identify celestial regions observed by a nanosatellite star tracker without prior attitude information.

The project includes astronomical catalogue preprocessing, gnomonic coordinate transformations, geometric feature engineering, class balancing, incremental data processing and multiclass neural-network classification.

**Technologies:** Python, NumPy, Pandas, Scikit-learn, TensorFlow, Numba, Matplotlib

[View repository](https://github.com/Sofia-Aguayo/Nanosatellite-star-tracker)
